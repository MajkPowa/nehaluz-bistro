# Nehaluz Bistro — verejná ukážka

Statická prezentácia a ukážkový objednávkový flow pre Nehaluz Bistro v Blatnom. Objednávky zostávajú iba v relácii prehliadača a do prevádzky sa neposielajú.

Tento repozitár obsahuje iba zostavený verejný web. Databáza, prihlasovacie údaje a vývojové zdroje sa nepublikujú.
