# Nehaluz Bistro — verejná ukážka

Statická prezentácia a ukážkový objednávkový flow pre Nehaluz Bistro v Blatnom. Súčasťou je ukážka administrácie (#/admin). Objednávky aj zmeny v nej zostávajú iba v prehliadači návštevníka a do prevádzky sa neposielajú.

Tento repozitár obsahuje iba zostavený verejný web. Databáza, prihlasovacie údaje a vývojové zdroje sa nepublikujú.
